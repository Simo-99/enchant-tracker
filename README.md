# Minecraft Enchantment Tracker (Frontend)

Dashboard React scura e moderna per monitorare gli incantesimi vanilla e custom sul tuo server Minecraft.

## Caratteristiche
- 🔍 Ricerca dinamica per nome e descrizione
- ⚖️ Filtri per sorgente (Vanilla / Custom), stato (Trovato / Mancante) e oggetto compatibile
- 📊 Barra di completamento e contatori in tempo reale
- 📝 Modal con dettagli estesi e lista incompatibilità/conflitti
- ⚡ Integrazione nativa con il backend Express locale (porta 3001)
